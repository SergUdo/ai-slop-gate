📜 Definitions & Principles (Locked for Project)
Provider Contract (fixed)

Providers must return data in this shape (no PASS/FAIL):

ProviderObservation:
  provider: str            # e.g. "gemini", "local-llama"
  model: str
  observations: list[Observation]
  raw_text: str            # raw output from model if applicable

Observation:
  category: "quality" | "style" | "hallucination"
  signal: "positive" | "neutral" | "negative"
  confidence: float        # 0.0–1.0
  message: str
  evidence:
    file: str | None
    line: int | None


LLM providers should never make PASS/FAIL decisions; that is the job of the policy evaluation layer.

🛡️ Why This Matters

This project’s purpose is to provide quality gates for AI-generated code.
If providers start doing decisions internally, the system becomes:

❌ opaque
❌ inconsistent
❌ non-deterministic

Instead, we must keep:

🟢 providers as sensors
🔵 policy as decision engine
🟠 workflows as enforcement layer

This architecture enables:

reuse across GitHub, GitLab, Bitbucket

offline testing

reproducibility
